# Controle de Gastos CLI

## 📌 Problema
Muitas pessoas têm dificuldade em controlar seus gastos diários.

## 💡 Solução
Aplicação simples em linha de comando para registrar e visualizar gastos.

## 👥 Público-alvo
Qualquer pessoa que deseja organizar suas finanças.

## ⚙️ Funcionalidades
- Adicionar gastos
- Listar gastos
- Ver total

## 🛠 Tecnologias
- Python
- Pytest
- Flake8
